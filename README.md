## 🌟 Fitur Utama

- ✅ Manajemen tugas (Task Manager)
- ✅ Perencanaan (Plan)
- ✅ Dashboard dengan statistik
- ✅ Autentikasi (Login & Register)
- ✅ Profile pengguna dengan kustomisasi
- ✅ Dark/Light mode
- ✅ Notifikasi & pengingat

## 🔐 Fitur Autentikasi

### Login
- Masuk dengan email dan password
- Validasi form
- Error handling

### Register
- Daftar akun baru dengan nama, email, dan password
- Konfirmasi password
- Validasi email unik

### Profile
- Edit nama, email, dan bio
- Upload foto profil (URL)
- Lihat informasi akun

### Logout
- Keluar dari akun melalui halaman Settings
- Konfirmasi sebelum logout
